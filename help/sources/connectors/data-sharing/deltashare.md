# [!DNL Deltashare]

È possibile utilizzare il connettore di origine [!DNL Deltashare] per stabilire una connettività sicura ai server [!DNL Databricks Delta Sharing] e creare set di dati virtuali in Adobe Experience Platform. Con questa funzione, puoi eseguire query sui set di dati virtuali, esaminare e mappare tabelle esterne agli schemi Experience Data Model (XDM) e sfruttarli nelle applicazioni e nei servizi Experience Platform. Tramite [!DNL Deltashare] è possibile evitare l&#39;acquisizione fisica dei set di dati, riducendo in tal modo la duplicazione, i costi di storage e il sovraccarico operativo.
